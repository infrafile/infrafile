# dnscontrol JSON 契约（v1）

`infrafile dnscontrol [目录] --json` 返回：

```json
{"version":"v1","config":"// Generated by infrafile...\n","domains":["example.com"]}
```

config 是完整 DNSControl JS 字符串，domains 为按名称排序的已生成 zone。无显式 DNS 记录的 Domain 和归档记录不参与；没有符合项时 domains 为 `[]`，config 仍包含说明和 REG_NONE 定义。records 可以为空，该 zone 仍生成 NO_PURGE 配置。

退出 0 成功，2 数据仓、字段、重复记录或 CNAME 冲突等错误；失败 stdout 为空。此命令不联网、不解析凭据、不写文件。字段、默认 TTL 与代理行为见[指南](../control.md)。
