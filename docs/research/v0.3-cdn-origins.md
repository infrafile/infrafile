# v0.3 M2 回源接口核对

2026-10-28 核对官方资料。以下是源码映射及虚构 HTTP 回放覆盖，不是实际账号验收；所有调用只读。端口、协议仅取明确字段，鉴权对象、证书、规则表达式和任意 API 原文不进入快照。

| 厂商 | 采集接口与预算 | 文档中的权限 | 映射与未知边界 |
| --- | --- | --- | --- |
| 阿里云 | 原清单后，每域名 DescribeCdnDomainDetail + DescribeCdnDomainConfigs；最多增加 400 次请求。详情接口限 30 次/秒 | 原 DescribeUserDomains 加 cdn:DescribeCdnDomainDetail、cdn:DescribeCdnDomainConfigs，可限定 domain 资源 | SourceModels.SourceModel 的 Content/Port；forward_scheme 或 ali_origin_port_scheme 的显式协议/端口。条件 ParentId、多个协议策略、高级 origin/edge 配置保留未知；组合端口不折叠。未配置协议不从端口猜测 |
| 腾讯云 | 开启后以 DescribeDomainsConfig 替代 DescribeDomains，Offset/Limit=100；正常满页为 2 页，非满页逐次前进至总数，最多 200 页；接口限 20 次/秒 | DescribeDomainsConfig，CAM 支持 domain 资源授权 | Origins + BackupOrigins；IPv4/DNS 的端口/权重语法及裸 IPv6；OriginPullProtocol。PathRules/PathBasedOrigin、SpecificConfig 区域覆盖、启用 RuleEngine 不判断全局一致；不保留鉴权及 RuleEngine.Content |
| 百度云 | 清单后，每域名 GET /v2/domain/{domain}/config?originConfig 与完整 /config；最多增加 400 次请求 | 原 QueryDomainList 加 QueryDomainConfig，后者支持 domain/{domainName} | originConfig.addr、upstreamProtocol、httpPort/httpsPort；星号协议映射 follow，两个端口不同则单端口未知。isp 及 pageRules_originConfig/pageRules_origins 为条件范围；完整配置文档的无条件示例省略 pageRules。thirdBucketAuth、probeUrl、证书和 Host header 不保留 |
| 天翼云 | 三个 area_scope 的原列表后，每域名/产品请求 /domain/query-domain-detail；最多增加 200 次请求。文档限 10000 次/分钟、并发 100 | **尚未确认公开的 API 级最小 IAM action**；不能用控制台权限名称冒充。须在真实只读验收确认 | origin[].origin/port；仅 top-level 与 https_basic.origin_protocol 明确一致时使用协议，follow_request 映射 follow。origin[].protocol 是源站类型，不当传输协议。区域不匹配、XOS 未明确关闭为未知；basic_conf 端口冲突则端口未知；不保留 XOS ak/sk |
| Cloudflare | 原 zones/DNS 分页后，每 zone GET /zones/{id}/rulesets/phases/http_request_origin/entrypoint；最多增加 200 次请求 | 原 Zone Read、DNS Read 加 Origin Read | 只比较单条明确 enabled=true、action=route、expression=true 的规则，取 action_parameters.origin.host/port。多个启用规则、条件、缺 host 均未知；Host header、SNI 不作目标，协议不可观测。无 entrypoint 的 404 按采集失败处理，保留旧快照 |

每实例 `collect_origin` 默认关闭。开启后最多处理 200 个 CDN 条目/zone，天翼相同域名的不同区域计为不同条目。请求串行、共享实例总超时（默认 30s），每次 HTTP 响应上限 4 MiB，最终插件结果同样有大小限制；不自动重试限流或权限失败。清单沿用原分页校验。超限、取消、HTTP/业务错误或无效响应使该实例失败，不发布部分回源结果。大账号应使用供应商支持的权限范围限定采集账号，不能靠静默截断声称完整。

当前模型只审计配置的主机集合及共同端口/协议，不计算优先级、权重、请求命中规则或区域路由。来源不明的字段保留未知，不复制任意厂商扩展。回执匹配是本地证据对应关系，不证明远端授权或瞬时一致性。未增加任何云写接口。
